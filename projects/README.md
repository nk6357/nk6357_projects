# Как добавить проект

Для проекта №1 создайте три обычных текстовых файла в этой папке:

- `1.txt` — название проекта (обязательно)
- `link1.txt` — полная ссылка на проект (обязательно)
- `about1.txt` — описание проекта (необязательно)

Для следующих проектов используйте номера `2`, `3`, `4` и так далее. Карточки сортируются по номеру. После отправки изменений на GitHub сайт обновится автоматически.
