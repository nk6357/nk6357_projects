# Портфолио nk6357

Статический адаптивный сайт-портфолио для GitHub Pages.

## Что положить в корень

1. Шрифт `LEMONMILK-RegularItalic.otf` уже находится в корне.
2. Файлы проектов — в папку `projects` по инструкции внутри неё.

После push в ветку `main` или `master` GitHub Actions автоматически пересоберёт и опубликует сайт. При первой публикации откройте **Settings → Pages** репозитория и выберите **Source: GitHub Actions**.

## Локальный просмотр

```bash
npm install
npm run dev
```

## Перед публикацией

В `app/Portfolio.tsx` замените `[ФИО ВЛАДЕЛЬЦА]` на ФИО владельца сайта и при необходимости уточните контакт для юридических обращений. Юридические тексты являются базовыми шаблонами для портфолио без форм и аналитики; при добавлении сбора данных их нужно пересмотреть.
